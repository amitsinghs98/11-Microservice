# Experience and Approval Sheet: David Esper

Fill this in for the 16 completed money pages. Each page has one experience section, the part readers trust most, and only you can write it.

## How to fill it in

1. Write 2–5 sentences of **your own** first-hand experience between `<<<` and `>>>`: a number you measured, a client situation (anonymised is fine), a mistake you made, or what surprised you. Plain text only; a blank line starts a new paragraph.
2. If you've read the page and are happy for it to be published, change `Approved: no` to `Approved: yes`.
3. Save the file and run:

```bash
python3 scripts/apply_experience.py
```

The script puts your text in place of each page's placeholder and marks the approved pages, so they go into the sitemap and can be indexed. Blocks left empty are skipped.

Rules: only real experience, no figures you didn't see yourself, and no client names without permission. If you've no experience for a page, leave it empty and don't approve it.
