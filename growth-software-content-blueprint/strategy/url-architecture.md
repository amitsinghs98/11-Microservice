# URL Architecture

The physical directory structure under `site/` mirrors the public URL. Serve `site/` as the web root: `site/best/seo-software/index.html` is served at `/best/seo-software/`.

The canonical list of URLs is **`strategy/url-manifest.json`**. It is generated by `scripts/build_manifest.py` from the source map. All internal links must use a `public_path` from it.

## Families

| Family | Pattern | Used for | Count |
|---|---|---|---|
| Topical hub | `/growth-stack/` | Central umbrella hub (H00, not counted) | 1 |
| Category hubs | `/categories/{seo,ai-content,email-outreach,crm-lead-gen,automation-analytics}/` | One per cluster (H01–H05, not counted). Slugs are taken verbatim from DOCX §3. | 5 |
| Best-of | `/best/{topic}/` | Listicles and pillars. The source slug has its leading `best-` removed to avoid `/best/best-…/`. | 56 |
| Comparisons | `/compare/{a}-vs-{b}/` | Head-to-head product pages (source slug kept) | 11 |
| Alternatives | `/alternatives/{product}/` | Switch-intent pages. Follows DOCX §3 `/alternatives/{product}/`, for example `/alternatives/semrush/`. | 14 |
| Pricing | `/pricing/{product-or-category}/` | Cost guides (DOCX §3 family) | 5 |
| Guides | `/guides/{slug}/` | How-to, informational and strategic guides | 14 |
| Software profiles | `/software/{product}/` | **Deferred.** No pages exist and none are linked. | 0 |
| Index | `/` | Plain QA directory (`site/index.html`), not a marketing homepage | 1 |

The brief's suggested `/categories/seo-software/` pattern was overridden by the DOCX's explicit `/categories/seo/` hub URLs, because the DOCX is the source of truth.

The `/pricing/` family is an addition to the brief's family list. The DOCX defines it explicitly, and it keeps cost guides from being misfiled as best-of or how-to pages.

## Rules

- Lowercase, hyphen-separated, trailing slash, no dates or years.
- Internal links are root-relative (`/compare/semrush-vs-ahrefs/`), never file paths or preview URLs.
- Each URL has exactly one canonical tag: `https://YOUR-DOMAIN.example{public_path}`.
- The domain lives only in `site.config.json`. Before launch, set the real domain there and run `python3 scripts/apply_config.py` to rewrite canonicals and titles across all pages, then rebuild the sitemap.
- To change a URL after launch, add a 301 redirect, update the manifest, and re-run `check_internal_links.py`.

## Source slug → final path

Every article's original DOCX slug is preserved in `url-manifest.json` (`source_slug`) and in `master-300-article-map.csv` (`suggested_slug`), next to its final `public_path`.
