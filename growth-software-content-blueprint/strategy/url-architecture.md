# URL Architecture

**Flat, single-segment URLs.** The owner decided this on 5 November 2026: every page lives one level below the root, with the page type expressed in the slug instead of a folder (`/best-seo-software/`, not `/best/seo-software/`). The physical layout under `site/` mirrors the public URL: `site/best-seo-software/index.html` is served at `/best-seo-software/`.

The canonical list of URLs is **`strategy/url-manifest.json`**, generated by `scripts/build_manifest.py` (see `flatten()`). Every internal link must use a `public_path` from it. `strategy/url-migration-map.csv` records each page's earlier nested path. Nothing was ever published at those nested paths, so no redirects are needed today. Keep the file in case a staging copy was shared.

## Families

| Family | Pattern | Example | Count |
|---|---|---|---|
| Topical hub | `/growth-stack/` | H00, the umbrella hub | 1 |
| Cluster hubs | `/{cluster}/` | `/seo/`, `/email-outreach/`, `/product-led-growth/` (H01–H15) | 15 |
| Best-of (listicles and the 5 pillars) | `/best-{topic}/` | `/best-ai-writing-tools/` | 230 |
| Comparisons | `/{a}-vs-{b}/` | `/semrush-vs-ahrefs/` | 20 |
| Alternatives | `/{product}-alternatives/` | `/instantly-alternatives/`, `/semrush-alternatives/` | 18 |
| Pricing | `/{topic}-pricing/` | `/seo-software-pricing/`, `/crm-pricing/` | 6 |
| Guides | `/{slug}/` | `/seo-tool-stack/`, `/choose-email-marketing-software/` | 26 |
| Software profiles | `/software/{product}/` | **Deferred.** No pages exist and none are linked. | 0 |
| Index | `/` | Plain QA directory (`site/index.html`), not a marketing homepage | 1 |

## Slug rules (`flatten()`)

- Best-of: prefix `best-` unless the slug already starts with it, so you never get `best-best-…`.
- Alternatives: append `-alternatives` unless the slug already contains it, e.g. `/shopify-alternatives-for-brands-requiring-more-store-control/`.
- Pricing: use the source slug when it contains `pricing` (e.g. A037 → `/ai-content-tool-pricing/`); otherwise append `-pricing`.
- Comparisons, guides and hubs keep their slug as is.
- The build asserts that all 316 paths are unique, so a future slug that collides with a hub or another page fails loudly.

## Rules

- Lowercase, hyphen-separated, trailing slash, no dates or years.
- Internal links are root-relative (`/semrush-vs-ahrefs/`), never file paths or preview URLs.
- Each URL has exactly one canonical tag: `https://YOUR-DOMAIN.example{public_path}`. JSON-LD breadcrumbs use the same URLs.
- Hierarchy is carried by breadcrumbs and internal links (Home → hub → page), not by folders.
- The domain lives only in `site.config.json`. Before launch, set the real domain there and run `python3 scripts/apply_config.py`, then rebuild the sitemap.
- Reserve root slugs you will need for the product (e.g. `/about/`, `/contact/`, `/software/`) so that no article takes them.
- To change a URL after launch, add a 301 redirect, update the manifest, and re-run `check_internal_links.py`.

## Source slug → final path

Every article's original slug is preserved in `url-manifest.json` (`source_slug`) and in `master-300-article-map.csv` (`suggested_slug`), next to its final `public_path`.
